# AGENTS.md

## ROS 2 environment

ROS 2 (Lyrical Luth), colcon, and the C/C++ toolchain are provided by the pixi environment defined in `pixi.toml`. There is no system ROS install.

Run every command that builds, runs, or inspects ROS 2 inside the pixi environment:

```bash
pixi run build   # colcon build over src/ plus any upstream description packages
pixi run bash -c "source install/setup.bash && ros2 run <pkg> <node>"
pixi shell   # interactive shell with the environment activated
```

Do not call `ros2`, `colcon`, `cmake`, or the compilers directly from the host shell. Add new dependencies with `pixi add <package>` (ROS packages are named `ros-lyrical-<name>`), not with apt or pip.

## External packages

Upstream vendor repos live in `external_packages/` as git submodules (clone with `git submodule update --init`). Only their description packages are built (see the `build` task in `pixi.toml`). Do not edit files inside the submodules; copy a file into `src/` and modify the copy instead.

## Simulation model

The URDF in `src/my_robot_description/urdf/` is the only robot description. `src/my_robot_simulation/mujoco/mujoco_description_formatted.xml` and `mujoco/assets/` are generated by `pixi run gen-mjcf`; never hand-edit them. MuJoCo-only additions go in `mujoco_inputs.xml`, `scene.xml`, or a post-processing script.
